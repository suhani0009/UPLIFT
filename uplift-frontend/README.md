# UPLIFT Frontend

Frontend for the UPLIFT NGO Donor & Donation Management Platform.

## Tech Stack

* React
* Vite
* JavaScript
* Axios
* HTML
* CSS

## Main Features

* Admin dashboard
* Donor management
* Donation management
* Transaction verification
* Contribution management
* Communication and engagement tracking
* CSV data import
* Public donation form
* Donor 360° view

## Run Locally

```bash
npm install
npm run dev
```

The frontend connects to the Spring Boot backend through REST APIs.
